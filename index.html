Documentación Oficial de Zechxel (Wiki)

Zechxel es un lenguaje de programación modular y de código abierto creado por Makebyr. Está diseñado para ofrecer una sintaxis altamente personalizable que transpila directamente a C/C++ y permite integrar código HTML/Web de forma nativa dentro de archivos con extensión .zh.

📁 Estructura del Directorio

Al descomprimir el paquete oficial con ditrar.exe dentro de una carpeta dedicada (por ejemplo, C:/zechxel), el sistema organiza sus módulos de la siguiente manera:

zechxel/
└── src/
    ├── bin/
    │   └── zh.exe      # Compilador principal de Zechxel (agregar al PATH)
    ├── edit/
    │   └── dll.zhr     # Archivo de configuración del Lexer (mapeo de sintaxis original)
    ├── lib/            # Librerías estándar y dependencias (ej. soporte gráfico/raylib)
    └── resuerces/
        ├── zres.o      # Recursos compilados del sistema
        └── icon.o      # Objeto de recursos para iconos de ejecutables
Nota de instalación: Asegúrate de añadir la ruta zechxel/src/bin a las Variables de Entorno (PATH) de Windows para ejecutar el compilador desde cualquier consola.
